# Household Chore Tool — MVP Project Spec (No Bars)

## 1. Product Goal
A calm, minimal household chore tool that helps people manage recurring and one‑off chores through weekly rotation, simple transparency, and low‑pressure design.  
No notifications, no analytics, no visual meters — just clarity and predictability.

---

## 2. Core Features (MVP)

### Weekly Rotation Engine
A predictable 7‑day cycle that assigns each household member one chore per week.
- Automatic weekly rotation  
- Manual reassignment (with required note)  
- Rotation countdown (“3 days left”)  
- Fairness emerges naturally from rotation order  

### Chore Dashboard
A simple, text‑based overview of the household’s current state.
- Members and roles  
- Assigned chore + difficulty (Light / Medium / Heavy)  
- Streak indicator (text only: “3 weeks consistent”)  
- Access to one‑off backlog  
- No bars, meters, or visual load indicators  

### Chore History
A minimal log of what happened.
- Completed  
- Skipped (with note)  
- Reassigned (with note)  
- Date only — no timestamps, no threads  
- No analytics  

### One‑Off Backlog
A separate space for non‑recurring chores.
- Add one‑off tasks  
- Mark complete  
- Skip with note  
- Keeps dashboard uncluttered  

---

## 3. Non‑Goals (Explicit Exclusions)
- No bars (fairness, load, progress, or otherwise)  
- No notifications  
- No calendar integration  
- No mood layers  
- No daily focus  
- No analytics  
- No gamification  
- No AI chore suggestions
