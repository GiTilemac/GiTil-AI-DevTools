# Included Features

## 1) Recurring Chore Engine
Manages all repeating household responsibilities.

Includes:
- Weekly rotation  
- One assigned chore per member  
- Difficulty levels  
- Streak tracking  
- Fairness bars  
- Complete  
- Skip with note  
- Manual reassignment with note  
- History (completed / skipped / reassigned)

## 2) One-Off Task Backlog
A simple space for tasks that do not repeat.

Includes:
- Add one-off task  
- Complete one-off task  
- Skip with note  

## 3) Household Structure
The minimal identity layer required for assignments and fairness.

Includes:
- Member list (names only)  
- One role per member  
- One chore assignment per rotation period  
- Identity used in fairness bars and history
